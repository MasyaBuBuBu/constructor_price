КОНСТРУКТОР РАСЧЁТА ЦЕНЫ v3

В шагах уже собран пример «Блэквуд» из техзадания — нажмите «Рассчитать» и сверьте итог (в примере из ТЗ: 23 337,28).
Исходные данные
Записать МС: (ПС + РТ × Цена м.пог.) / НДС, К. Результат подставится в поле «МС, руб.» и попадёт в историю. Значение МС можно также ввести вручную.
Множители (×)
Делители (÷)
Суммы (+)
Чтобы сумма вычиталась — впишите её со знаком минус (например, Ящик = −2500).
Проценты (+ %)
Шаги расчёта (порядок = порядок применения)
Галочка слева — включить шаг в расчёт. Стрелки — менять порядок. Крестик — удалить.
«Взять значение» — начать шаг с выбранного значения (МС, СО, сохранённого и т. д.). Остальные шаги по умолчанию продолжают предыдущий результат.
